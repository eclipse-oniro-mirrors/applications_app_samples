| 测试功能 | 预置条件 | 输入 | 预期输出 | 是否自动 | 测试结果 |
| -------------------------------- | -------------------------------- | -------------------------------- | -------------------------------- | -------------------------------- | -------------------------------- |
| 创建会话 | 设备正常运行，应用已安装，端侧模型已放置到 `/data/storage/el2/base/files/Qwen2_5_0_5B_CPU_Q4` | 调用 createSession，模型路径为默认路径 | 返回错误码 0（OH_QOS_GEWU_OK），销毁会话返回 0 | 是 | 待真机执行 |

## 说明

1. 自动化用例位于 `entry/src/ohosTest/ets/test/Ability.test.ets`，用例命名遵循"包名_测试功能_序号"规范（包名常量为 `GewuService_`），DOMAIN 为 0xF811，每条用例前有注释，用例开头与结尾均有日志打印，每条断言前打印参数信息。
2. 用例依赖设备上的端侧推理模型：执行前需将模型（如 Qwen2.5-0.5B CPU 量化模型）放置到应用沙箱 `/data/storage/el2/base/files/Qwen2_5_0_5B_CPU_Q4` 目录。模型缺失时，创建会话用例会返回非 0 错误码而非通过，因此执行前需确认模型已就绪。DevEco Studio 直接执行用例时如果卸载重装了应用，可能会导致沙箱内模型文件缺失。
3. 提交请求用例为同步等待推理完成的场景，推理耗时与设备算力相关，用例整体执行时间取决于端侧推理速度。
4. 中止请求用例在请求执行完成后调用 abortRequest，接口返回的错误码与请求完成后的句柄状态相关（预期为 OH_QOS_GEWU_NOENT 等定义域内的错误码），用例断言返回值非负，用于验证接口不崩溃、句柄状态正确复位。
