# AVCodecSample 手工测试用例

## 1. 文档说明

本文档用于指导 AVCodecSample 的手工功能、兼容性和稳定性测试，覆盖以下主要链路：

- 文件管理器、图库选取媒体文件；
- 音视频解封装、视频解码、音频解码与播放；
- SurfaceMode 和 BufferMode 视频送显；
- BufferMode 解码帧可选 dump；
- 同步/异步解码、软硬件解码、倍速和画面变换；
- 结构化播放状态、媒体时长、播放位置，以及解封装媒体详情显示；
- 相机采集、音频采集、音视频编码和 MP4/FLV 封装；
- 权限、异常媒体文件、连续播放录制等异常与稳定性场景。

测试结果建议填写为：

| 结果 | 含义 |
|---|---|
| Pass | 实际结果符合预期 |
| Fail | 实际结果不符合预期，并已记录缺陷 |
| Blocked | 受设备能力、环境或依赖问题阻塞 |
| N/A | 当前设备或版本不适用 |
| 未执行 | 尚未执行该用例 |

### 2.2 前置要求

1. 使用具备相机、麦克风和音频输出能力的真机安装应用。
2. 准备下表所列测试媒体，确保文件本身可以在设备自带播放器中正常播放。
3. 测试录制功能前，确认设备存在足够的媒体存储空间。
4. 测试 dump 前，建议先清理应用沙箱中旧的 `VideoDecoderOut_*` 文件，避免误判。
5. 涉及硬解、H.265、4K、60fps、HDR Vivid 的用例以设备实际能力为准；设备不支持时应验证应用能否提示或回退，结果可记录为 N/A。
6. 除特别说明外，每个播放用例至少观察 30 秒，短视频应完整播放到结束。
