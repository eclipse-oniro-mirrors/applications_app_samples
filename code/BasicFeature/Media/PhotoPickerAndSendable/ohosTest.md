## 测试步骤

1. 使用 DevEco Studio 打开工程，连接真机或模拟器；
2. 选择 `entry` 模块的 `ohosTest` 目标，执行 `Run 'entry' with Tests`；
3. 用例会在启动被测应用后依次点击首页场景入口，校验控件 id 是否存在，随后返回首页；
4. 「全量图库」场景在未配置 ACL 签名时只校验权限说明卡片与已加载数量文案，不强制授权。

## 备注

* 相册选择、最近照片依赖系统图库数据，自动化用例只校验页面结构，不校验具体图片内容；
* 跨线程编辑的完整链路（选择图片 → 调整参数 → TaskPool 处理 → 保存到沙箱）建议按 README 的使用说明手动验证，并补充到测试报告中。
