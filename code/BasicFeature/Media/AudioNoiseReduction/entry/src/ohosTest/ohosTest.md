# AudioNoiseReduction 测试用例归档

## 用例表

| 测试功能 | 预置条件 | 输入 | 预期输出 | 是否自动 | 测试结果 |
|---------|---------|------|---------|---------|---------|
| 拉起应用 | 设备正常运行 | | 成功拉起应用，显示主页 | 是 | Pass |
| 主页展示 | 设备正常运行 | | 展示降噪模式入口按钮和简化示例入口按钮 | 是 | Pass |
| 进入降噪模式Demo | 位于主页 | 点击"进入降噪模式 Demo" | 跳转主页面，显示显示屏、流列表和操作区 | 是 | Pass |
| 创建录音流 | 位于主页面，已授权麦克风权限 | 点击"+ 新建"，选择 SourceType/采样率/声道，点击"确定" | 流列表新增一条流卡片，显示屏显示创建成功日志 | 是 | Pass |
| 设置降噪模式 | 已创建录音流并选中 | 滑动到降噪模式操作区，点击"FIDELITY"按钮 | 显示屏显示设置成功日志，流详情中当前模式更新为 FIDELITY | 是 | Pass |
| 查询降噪模式 | 已创建录音流并选中 | 点击"查询当前"按钮 | 显示屏显示查询结果，流详情中当前模式更新为实际值 | 是 | Pass |
| 注册回调 | 已创建录音流并选中 | 滑动到回调操作区，点击"注册回调"按钮 | 显示屏显示注册成功日志，流详情中回调状态更新为已注册 | 是 | Pass |
| 注销回调 | 已注册回调 | 点击"取消指定"按钮 | 显示屏显示注销成功日志，流详情中回调状态更新为未注册 | 是 | Pass |
| 查询支持的降噪模式 | 已创建录音流并选中 | 点击"查询支持"按钮 | 显示屏显示支持的模式列表 | 是 | Pass |
| 进入菜单页 | 位于主页面 | 点击标题栏"≡"图标 | 跳转菜单页，显示接口配置、默认配置、显示选项等 | 是 | Pass |
| 切换API模式 | 位于菜单页 | 点击"API 模式"菜单项 | API模式在 C API 和 JS API 之间切换 | 是 | Pass |
| 进入简化示例 | 位于主页 | 点击"简化示例 (JS + C API)" | 跳转简化示例页面，显示 JS API 和 C API 对照 | 是 | Pass |
| 简化示例创建录音流 | 位于简化示例页面，已授权麦克风权限 | 选择 SourceType，点击 JS API "Create" 按钮 | State 更新为 Created | 是 | Pass |
| 简化示例设置降噪模式 | 简化示例已创建录音流 | 点击 JS API "Set FIDELITY" 按钮 | Mode 更新为 FIDELITY | 是 | Pass |
| 简化示例注册回调 | 简化示例已创建录音流 | 点击 JS API "Register" 按钮 | Callback 显示 Registered | 是 | Pass |
| 简化示例注销回调 | 简化示例已注册回调 | 点击 JS API "Unregister" 按钮 | Callback 显示 Unregistered | 是 | Pass |
| 释放录音流 | 已创建录音流并选中 | 点击"Release"按钮 | 流列表移除该流，显示屏显示释放成功日志 | 是 | Pass |
