# 音频编创测试用例归档

## 用例表

| 测试功能         | 预置条件 | 输入                  | 预期输出 | 是否自动 |
|--------------|----------|---------------------|----------|----------|
| 拉起应用         | 设备正常运行 | -                   | 成功拉起应用，进入首页 | 是 |
| 播放音频         | 位于首页 | 点击 "播放音频" 按钮        | 播放原始音频成功，显示成功信息 | 是 |
| 停止播放         | 音频正在播放 | 点击 "停止播放" 按钮        | 停止播放成功，显示成功信息 | 是 |
| 添加均衡器效果       | 位于首页 | 点击 "添加音频效果" 按钮，选择效果类型为"均衡器效果"，配置预置效果或频带增益后点击"确定" | 添加均衡器效果成功，显示成功信息 | 是 |
| 添加声音美化效果      | 位于首页 | 点击 "添加音频效果" 按钮，选择效果类型为"声音美化效果"，选择美化类型后点击"确定" | 添加声音美化效果成功，显示成功信息 | 是 |
| 添加降噪效果         | 位于首页 | 点击 "添加音频效果" 按钮，选择效果类型为"降噪效果"，点击"确定" | 添加降噪效果成功，显示成功信息 | 是 |
| 添加声场效果         | 位于首页 | 点击 "添加音频效果" 按钮，选择效果类型为"声场效果"，选择声场类型后点击"确定" | 添加声场效果成功，显示成功信息 | 是 |
| 添加环境效果         | 位于首页 | 点击 "添加音频效果" 按钮，选择效果类型为"环境效果"，选择环境场景类型后点击"确定" | 添加环境效果成功，显示成功信息 | 是 |
| 添加空间渲染效果（位置） | 位于首页 | 点击 "添加音频效果" 按钮，选择效果类型为"空间渲染效果"，选择场景为"位置"，配置 x/y/z 参数后点击"确定" | 添加空间渲染效果成功，显示成功信息 | 是 |
| 添加空间渲染效果（旋转） | 位于首页 | 点击 "添加音频效果" 按钮，选择效果类型为"空间渲染效果"，选择场景为"旋转"，配置 x/y/z、环绕时间、环绕方向后点击"确定" | 添加空间渲染效果成功，显示成功信息 | 是 |
| 添加空间渲染效果（扩展） | 位于首页 | 点击 "添加音频效果" 按钮，选择效果类型为"空间渲染效果"，选择场景为"扩展"，配置半径、角度后点击"确定" | 添加空间渲染效果成功，显示成功信息 | 是 |
| 添加传统变声效果      | 位于首页 | 点击 "添加音频效果" 按钮，选择效果类型为"传统变声效果"，选择说话人性别、变声类型、音高后点击"确定" | 添加传统变声效果成功，显示成功信息 | 是 |
| 添加通用变声效果      | 位于首页 | 点击 "添加音频效果" 按钮，选择效果类型为"通用变声效果"，选择通用变声类型后点击"确定" | 添加通用变声效果成功，显示成功信息 | 是 |
| 添加变速变调效果      | 位于首页 | 点击 "添加音频效果" 按钮，选择效果类型为"变速变调效果"，配置速度 speed、音高 pitch 后点击"确定" | 添加变速变调效果成功，显示成功信息 | 是 |
| 播放添加音频效果后音频 | 已添加音频效果 | 点击 "播放添加音频效果后音频" 按钮 | 播放添加音频效果后音频成功，显示成功信息 | 是 |
| 音源分离         | 位于首页 | 点击 "音源分离" 按钮        | 音源分离成功，显示成功信息 | 是 |
| 播放伴奏         | 已完成音源分离 | 点击 "播放伴奏" 按钮        | 播放伴奏成功，显示成功信息 | 是 |
| 播放人声         | 已完成音源分离 | 点击 "播放人声" 按钮        | 播放人声成功，显示成功信息 | 是 |
| 混音与级联        | 已完成音源分离 | 点击 "混音与级联" 按钮       | 混音与级联成功，显示成功信息 | 是 |
| 播放混音         | 已完成混音与级联 | 点击 "播放混音" 按钮        | 播放混音成功，显示成功信息 | 是 |
| 播放实时预览       | 位于首页 | 点击 "播放实时预览" 按钮      | 播放实时预览成功，显示成功信息 | 是 |
| 播放空间渲染       | 已完成音源分离 | 点击 "播放空间渲染" 按钮      | 播放空间渲染成功，显示成功信息 | 是 |
| 音频格式转换       | 位于首页 | 点击 "格式转换" 按钮        | 格式转换成功，显示成功信息 | 是 |
| 调试           | 正在播放实时预览 | 点击 "调试" 按钮          | PrintInfo 测试成功，输出状态信息到文件 | 是 |
