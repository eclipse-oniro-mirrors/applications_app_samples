# 获取支持的编解码能力 测试用例归档

## 用例表

| 测试功能 | 预置条件 | 输入 | 预期输出 | 是否自动 | 测试结果 |
|---|---|---|---|---|---|
| 拉起应用 | 设备正常运行 |  | 成功拉起应用，显示主页 | 是 | Pass |
| 主页显示两个页签 | 成功拉起应用 |  | 页面显示"编解码器列表"与"场景验证"两个页签 | 是 | Pass |
| 查询视频解码器列表 | 位于编解码器列表页签 | 选择视频解码类别 | 列表展示解码器名称、MIME类型、软硬件类别 | 否 | Pass |
| 查询音频编码器列表 | 位于编解码器列表页签 | 选择音频编码类别 | 列表展示解码器名称、MIME类型、软硬件类别 | 否 | Pass |
| 查看编解码器详情 | 位于编解码器列表页签 | 点击列表项 | 详情页展示宽高范围、帧率范围、码控模式等能力 | 否 | Pass |
| 编解码器类别枚举验证 |  |  | 视频解码=0, 视频编码=1, 音频解码=2, 音频编码=3 | 是 | Pass |
| 类别唯一性验证 |  |  | 四个类别取值互不相同 | 是 | Pass |
| native库存在性验证 |  |  | libcapability.so包含getCodecList、getCodecDetail、runScenario接口 | 是 | Pass |
| 执行方式一获取能力实例 | 位于场景验证页签 | 点击按MIME获取场景 | 结果包含系统推荐音频AAC解码器信息 | 否 | Pass |
| 执行安全解码器筛选场景 | 位于场景验证页签 | 点击DRM安全解码器场景 | 返回H.264安全解码器查询结果 | 否 | Pass |
| 场景结果缓存验证 | 已执行任一场景 | 再次点击同一场景 | 直接返回缓存结果，不重复创建实例 | 否 | Pass |
| 码控模式常量验证 |  |  | CBR=0, VBR=1, CQ=2, CBRHQ=4 | 是 | Pass |
| MIME类型常量验证 |  |  | video/avc含video前缀, audio/mp4a-latm含audio前缀 | 是 | Pass |
