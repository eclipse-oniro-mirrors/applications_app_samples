## 新增自动化测试覆盖

| 测试类别 | 主要覆盖内容 | 用例规模 |
| --- | --- | --- |

| 字幕状态 | 同步阈值、seek、倍速、边界、异常 | 500+ |
| 文件 I/O | 临时文件写入/读取/截断、fd 描述符 | 300+ |
| 播放器契约 | AVPlayer 状态、Native API、时间轴 | 1,000+ |
| 资源与管道 | rawfile、m3u8、同步、资源完整性 | 800+ |
| UI 冒烟 | 页面启动、播放控制、组件可见性 | 少量 |
