# 测试用例归档

## 用例表

| 测试功能                       | 预置条件                                      | 输入                                                         | 预期输出                              | 是否自动 | 测试结果 |
| ------------------------------ | --------------------------------------------- | ------------------------------------------------------------ | ------------------------------------- | -------- | -------- |
| 创建重定向器                   | 设备正常运行，已授权 TRAFFIC_FILTER 权限      | groupId、priority、packetCopyLen、nfqueueMaxlen、nfqueueFlags | 显示 Redirector created               | 是       | pass     |
| 销毁重定向器                   | 已创建重定向器                                | 无                                                           | 显示 Redirector destroyed             | 是       | pass     |
| 添加重定向规则（基础模式）     | 已创建重定向器                                | 规则优先级、Hook Point、源/目的 IP/端口、代理 IP/端口等      | 显示 Rule added                       | 是       | pass     |
| 添加重定向规则（高级 JSON 模式） | 已创建重定向器                                | JSON 规则配置                                                | 显示 Rule added                       | 是       | pass     |
| 清空重定向规则                 | 已创建重定向器且已添加规则                    | 无                                                           | 显示 All rules cleared                | 是       | pass     |
| 加载规则模板                   | 已创建重定向器                                | basic / full                                                 | 成功加载模板 JSON                     | 是       | pass     |
| 查询连接所属进程               | 设备存在有效连接                              | 源/目的 IP、端口、协议                                       | 返回进程 pid/uid 或对应错误信息       | 是       | pass     |
