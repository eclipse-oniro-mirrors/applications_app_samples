# CarAwareness服务测试用例

## 用例表

| 测试功能                 | 预置条件     | 输入                 | 预期输出                 | 是否自动 | 测试结果 |
| ------------------------ | ------------ | -------------------- | ------------------------ | -------- | -------- |
| 订阅隔空手势 | 进入主界面 | 点击订阅隔空手势按钮 | 隔空手势状态显示"已订阅" | 是 | Pass |
| 取消订阅隔空手势 | 进入主界面 | 点击取消订阅隔空手势按钮 | 隔空手势状态显示"未订阅" | 是 | Pass |
| 订阅实时天气 | 进入主界面 | 点击订阅实时天气按钮 | 实时天气状态显示"已订阅" | 是 | Pass |
| 取消订阅实时天气 | 进入主界面 | 点击取消订阅实时天气按钮 | 实时天气状态显示"未订阅" | 是 | Pass |
| 订阅补能状态 | 进入主界面 | 点击订阅补能状态按钮 | 补能状态显示"已订阅" | 是 | Pass |
| 取消订阅补能状态 | 进入主界面 | 点击取消订阅补能状态按钮 | 补能状态显示"未订阅" | 是 | Pass |
| 查询能力列表 | 进入主界面 | 点击查询能力列表按钮 | 页面无崩溃，按钮响应正常 | 是 | Pass |
