# SetWindowLimitsByStartOptions测试用例归档

## 用例表

| 测试功能 | 预置条件 | 输入 | 预期输出 | 是否自动 | 测试结果 |
|------|------|------|------|------|------|
| 通过StartOptions启动目标窗口 | 位于只有一个应用的空白页 | 1、打开应用，进入示例主页<br/>2、点击"启动测试窗口"按钮 | 通过StartOptions启动WindowTestAbility，当前顶层Ability切换为WindowTestAbility | 是 | Pass |
| 窗口尺寸限制生效 | 位于只有一个应用的空白页 | 1、打开应用，点击"启动测试窗口"按钮<br/>2、在自由窗口状态下拖拽调节窗口大小 | 窗口宽度、高度被限制在StartOptions设置的最小值与最大值范围内（宽度600vp~1500vp，高度500vp~1000vp） | 是 | Pass |

### 使用说明

自由窗口尺寸限制相关用例仅在支持自由窗口的设备（如2in1、平板）上通过，普通手机仅通过页面展示与Ability启动类用例。
