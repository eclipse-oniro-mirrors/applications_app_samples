# SetWindowLimits测试用例归档

## 用例表

| 测试功能 | 预置条件 | 输入 | 预期输出 | 是否自动 | 测试结果 |
|------|------|------|------|------|------|
| 打开应用显示主页 | 位于只有一个应用的空白页 | 1、打开应用，进入示例主页 | 应用启动成功，主页正常显示"setWindowLimits."文字 | 是 | Pass |
| 窗口尺寸限制生效 | 位于只有一个应用的空白页 | 1、打开应用，应用启动时调用setWindowLimits设置窗口尺寸限制<br/>2、在自由窗口状态下拖拽调节窗口大小 | 窗口宽度、高度被限制在setWindowLimits设置的范围内（宽度600px~1500px，高度500px~1000px） | 是 | Pass |

### 使用说明

自由窗口尺寸限制相关用例仅在支持自由窗口的设备（如2in1、平板）上通过，普通手机仅通过页面展示类用例。
