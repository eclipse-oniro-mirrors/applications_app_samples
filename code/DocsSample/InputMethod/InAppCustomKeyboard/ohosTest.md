# 测试用例归档

## 用例表

| 测试功能 | 预置条件 | 输入 | 预期显示 | 是否自动 | 测试结果 |
| -------- | -------- | ---- | -------- | -------- | -------- |
| 启动应用 | 设备正常运行 | 编译hap包并安装运行 | 成功拉起应用，显示应用内自定义键盘页面 | 是 | 验证通过 |
| 注册代理输入法 | 应用已启动，应用获焦 | 点击“启用键盘”按钮 | 代理输入法注册成功，点击输入框拉起自定义键盘 | 否 | 验证通过 |
| 键盘输入 | 代理输入法已注册，自定义键盘已显示 | 点击数字按键（1-9、0）和字母按键（A） | 编辑框文本随按键输入变化 | 否 | 验证通过 |
| 退格删除 | 编辑框已有文本，自定义键盘已显示 | 点击“删除”按键 | 光标前一个字符被删除（退格行为） | 否 | 验证通过 |
| 收起键盘 | 自定义键盘已显示 | 点击“收起”按钮 | 自定义键盘隐藏，再次点击输入框可重新显示 | 否 | 验证通过 |
| 停用键盘 | 代理输入法已注册 | 点击“停用键盘”按钮 | 代理输入法注销，点击输入框使用系统输入法 | 否 | 验证通过 |
| 关闭示例 | 应用运行中 | 点击“关闭示例”按钮 | 应用完成注销与清理后关闭页面 | 否 | 验证通过 |
