# AddPrinterInApp 测试用例归档

## 用例表

| 测试功能                 | 预置条件                                    | 输入                              | 预期输出                         | 是否自动 | 测试结果 |
| ------------------------ | ------------------------------------------- | --------------------------------- | -------------------------------- | -------- | -------- |
| 拉起应用                 | 设备正常运行                                |                                   | 成功拉起应用并展示主界面         | 是       | Pass     |
| 必填信息校验             | 应用已拉起且打印机URI为空                   | 点击"添加打印机"按钮              | 页面提示补全必填信息             | 是       | Pass     |
| 应用内添加打印机         | 已声明PRINTER_DRIVER权限，输入真实打印机URI | 填写名称和URI后点击"添加打印机"按钮 | 接口返回true，系统打印机列表出现新增打印机 | 否 | Pass |
| 添加失败错误码提示       | 输入无法连通的打印机URI                     | 点击"添加打印机"按钮              | 页面展示错误码及对应排查提示     | 否       | Pass     |
