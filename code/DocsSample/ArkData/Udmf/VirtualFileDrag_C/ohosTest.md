# 功能验证

## 预置条件

使用 API 26.1.0 SDK 编译、签名安装，ROM 已包含虚拟文件拖拽能力；桌面或文件管理器可接收拖拽文件。工程配置为动态 ArkTS，测试依赖 Hypium 1.0.24。

## 自动化场景

在 DevEco Studio 中运行 `entry/src/ohosTest/ets/test/Ability.test.ets`，使用工程中的 `OpenHarmonyTestRunner`。用例按当前语言资源识别控件，不依赖固定中文文字。

| 用例编号/名称 | 步骤 | 预期现象 | 设备执行结果 |
| --- | --- | --- | --- |
| VirtualFileDragC_Document_001 | 启动应用，选择文档 | 显示文档的拖起提示 | 待执行 |
| VirtualFileDragC_Directory_002 | 选择目录 | 显示嵌套目录的拖起提示 | 待执行 |
| VirtualFileDragC_Archive_003 | 选择按需解压 | 显示解压文件的拖起提示 | 待执行 |

以上仅验证场景切换，不等价于跨应用 FUSE 读取通过。
