# 功能验证

## 预置条件

使用 API 26.1.0 SDK 编译并签名安装，ROM 已包含虚拟文件拖拽能力。目标为文件管理器或支持接收文件的桌面；需要观察普通读取过程时，可安装另一示例并使用其接收区。

| 用例 | 操作 | 预期现象 |
| --- | --- | --- |
| 文档导出 | 选择单文件并拖入目标，保存后打开 | 文本可打开且内容完整 |
| 嵌套目录 | 选择目录，拖入目标并打开目录 | 保留子目录及三份文档，无缺失 |
| 按需解压 | 选择压缩场景，准备后拖出，再由目标读取 | 准备时未解压；目标读取时解压，保存后内容完整 |
| 重复拖拽 | 前一次复制结束后再次拖出 | 两次均可保存，提供方未因前一次结束失效 |
| 普通应用接收 | 拖到文件管理器或桌面 | 目标无须使用虚拟文件接口即可保存、打开 |
| 接收区复制 | 拖到另一示例的绿色接收区 | 页面显示成功及保存位置，文件内容完整 |
| 网络分块读取 | 输入大于 10 MiB 的稳定 HTTPS Range 资源及准确大小，准备并拖出 | 准备时只探测一个字节；落入读取时按需下载，保存内容与源文件一致 |
| 网络参数错误 | 输入不支持 Range 的地址或错误大小并准备 | 页面提示失败，未使能新的拖拽 |
| 网络失败 | 大文件读取期间断开网络 | 目标读取失败，不将不完整内容当作正常文件 |
