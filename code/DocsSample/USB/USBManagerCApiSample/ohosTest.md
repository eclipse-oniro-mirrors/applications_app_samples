# USBManagerCApiSample 测试用例归档

## 用例表

| 测试功能 | 预置条件 | 输入 | 预期输出 | 是否自动 | 测试结果 |
|---------------|--------------|------------|---------------|------|------|
| 拉起应用 | 设备正常运行 | | 成功拉起应用，主页标题正常展示 | 是 | Pass |
| 主页展示 | 设备正常运行 | | 展示 ①~⑦ 步进按钮与日志面板 | 是 | Pass |
| 主页按钮点击 | 位于主页，连接USB外设 | 点击“① 获取设备信息” | 日志显示设备数量及 VID/PID、厂商、配置/接口/端点信息 | 是 | Pass |
| 主页按钮点击 | 位于主页，连接USB外设 | 点击“③ 查询权限” | 日志显示当前授权状态 | 是 | Pass |
| 主页按钮点击 | 位于主页，连接USB外设 | 点击“④ 申请权限” | 弹窗点击“允许”后日志显示用户允许 | 是 | Pass |
| 主页按钮点击 | 位于主页，连接USB外设 | 点击“⑤ 连接 ConnectDevice” | 日志显示 pipe {busNum, devAddress} | 是 | Pass |
| 主页按钮点击 | 位于主页，连接USB外设 | 点击“⑥ 取FD GetFileDescriptor” | 日志显示 fd | 是 | Pass |
| 主页按钮点击 | 位于主页，连接USB外设 | 点击“⑦ 关闭 ClosePipe” | 日志显示关闭结果 | 是 | Pass |
| 主页按钮点击 | 位于主页，连接USB外设 | 点击“② 释放设备信息” | 日志显示释放设备数量，列表清空 | 是 | Pass |
