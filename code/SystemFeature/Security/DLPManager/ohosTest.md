# DLPManager 测试用例归档

## 用例表

测试的前置条件：设备正常运行，应用具备所需系统权限。自动化用例在应用沙箱内自行创建测试数据，无需预先向公共文件路径放入文件；原依赖公共目录预置文件的 picker/文件页自动化用例已移除，相关功能保留为手工验证。
