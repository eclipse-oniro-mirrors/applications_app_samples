## 验证点

| 项目 | rk3568 | 大屏 |
|---|---|---|
| 服务启动 | 通过 startAbility 拉起 ScreenRecorderAbility，startId 为 1 时进入启动录屏分支 | 通过 startAbility 拉起 ScreenRecorderAbility，startId 为 1 时进入启动录屏分支 |
| 服务停止 | startId 非 1 时进入停止录屏分支，停止后服务正常退出 | startId 非 1 时进入停止录屏分支，停止后服务正常退出 |
| 录屏启动 | 创建媒体库视频资源后调用原生 startRecording，返回 0，状态切换为 Recording | 创建媒体库视频资源后调用原生 startRecording，返回 0，状态切换为 Recording |
| 录制参数 | 1920×1080、H.264、30fps、2Mbps，AAC-LC 48kHz 双声道，封装为 MP4 | 1920×1080、H.264、30fps、2Mbps，AAC-LC 48kHz 双声道，封装为 MP4 |
| 音频采集 | 同时采集麦克风与系统播放声，录屏文件包含对应音轨 | 同时采集麦克风与系统播放声，录屏文件包含对应音轨 |
| 文件命名 | 录制文件按 `REC_yyyyMMdd_HHmmss.mp4` 规则命名，时间戳与实际时间一致 | 录制文件按 `REC_yyyyMMdd_HHmmss.mp4` 规则命名，时间戳与实际时间一致 |
| 文件保存 | 视频写入媒体库 Photos，录制结束后可在「照片」中查看与播放 | 视频写入媒体库 Photos，录制结束后可在「照片」中查看与播放 |
| 悬浮计时窗 | 录制开始后左上角弹出悬浮窗，位置与尺寸符合 96,48/624×56 设计值 | 录制开始后左上角弹出悬浮窗，位置与尺寸符合 96,48/624×56 设计值 |
| 窗口属性 | 悬浮窗为 TYPE_FLOAT、透明背景、不可获焦，不影响前台应用操作 | 悬浮窗为 TYPE_FLOAT、透明背景、不可获焦，不影响前台应用操作 |
| 计时显示 | 计时文本按 HH:mm:ss 从 00:00:00 开始递增，停止后暂停不再变化 | 计时文本按 HH:mm:ss 从 00:00:00 开始递增，停止后暂停不再变化 |
| 录制指示 | 红色圆点以 800ms 周期闪烁，停止或异常后恢复常显 | 红色圆点以 800ms 周期闪烁，停止或异常后恢复常显 |
| 快捷键提示 | 悬浮窗展示「同时按下菜单键与音量减键，即可结束录屏」文案 | 悬浮窗展示「同时按下菜单键与音量减键，即可结束录屏」文案 |
| 快捷键结束 | 菜单键与音量减键同时按下触发一次结束回调，松开任一键后可再次触发 | 菜单键与音量减键同时按下触发一次结束回调，松开任一键后可再次触发 |
| 停止流程 | 先隐藏计时窗，再调用 stopRecording 并释放采集实例，随后弹出结束提示 | 先隐藏计时窗，再调用 stopRecording 并释放采集实例，随后弹出结束提示 |
| 结束提示 | 提示窗展示「录屏视频已存储到"照片"」，停留 3 秒后自动隐藏并结束服务 | 提示窗展示「录屏视频已存储到"照片"」，停留 3 秒后自动隐藏并结束服务 |
| 异常提示 | 录制异常时悬浮窗显示红色「未知错误,录制停止」，计时暂停，2 秒后服务自动退出 | 录制异常时悬浮窗显示红色「未知错误,录制停止」，计时暂停，2 秒后服务自动退出 |
| 状态机 | Idle/Recording/Stopped/Error 四态流转正确，非 Idle 不重复启动，非 Recording 不重复停止 | Idle/Recording/Stopped/Error 四态流转正确，非 Idle 不重复启动，非 Recording 不重复停止 |
| 状态回传 | 原生状态回调经线程安全函数回传至 ArkTS，悬浮窗与服务的状态保持同步 | 原生状态回调经线程安全函数回传至 ArkTS，悬浮窗与服务的状态保持同步 |
| 窗口复用 | 同名悬浮窗已存在时不重复创建，避免多窗口叠加与状态污染 | 同名悬浮窗已存在时不重复创建，避免多窗口叠加与状态污染 |
| 资源释放 | 服务销毁时统一销毁计时窗与提示窗并清空缓存，再次启动无残留窗口 | 服务销毁时统一销毁计时窗与提示窗并清空缓存，再次启动无残留窗口 |
| 提示窗定位 | 结束提示窗按屏幕宽度水平居中显示，布局无偏移与截断 | 结束提示窗按屏幕宽度水平居中显示，布局无偏移与截断 |
| 分辨率适配 | 尺寸换算按设备实际宽度与 1920 设计宽度等比缩放，悬浮窗与文案无错位 | 尺寸换算按设备实际宽度与 1920 设计宽度等比缩放，悬浮窗与文案无错位 |
| 分辨率上限 | 设置分辨率超过 3840×2160 或小于等于 0 时参数不生效，保持原采集分辨率 | 设置分辨率超过 3840×2160 或小于等于 0 时参数不生效，保持原采集分辨率 |
| 分辨率提示页 | 提示页展示「暂不支持」「当前设备分辨率过高，请降低分辨率」，长文案按跑马灯展示 | 提示页展示「暂不支持」「当前设备分辨率过高，请降低分辨率」，长文案按跑马灯展示 |
| 权限申请 | 相机屏幕采集、麦克风、读写媒体库、悬浮窗等权限声明完整，未授权时启动失败有日志且不崩溃 | 相机屏幕采集、麦克风、读写媒体库、悬浮窗等权限声明完整，未授权时启动失败有日志且不崩溃 |
| 中断处理 | 被并发录屏任务中断或麦克风不可用时进入 Error 状态并给出异常提示 | 被并发录屏任务中断或麦克风不可用时进入 Error 状态并给出异常提示 |
| 资源加载 | 中英文资源及 luping 图标、应用图标加载正常，无缺失与乱码 | 中英文资源及 luping 图标、应用图标加载正常，无缺失与乱码 |
| 服务生命周期 | 服务创建、请求、销毁各阶段回调正常，重复拉起无重复初始化 | 服务创建、请求、销毁各阶段回调正常，重复拉起无重复初始化 |
