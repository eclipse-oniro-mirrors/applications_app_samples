# TVPowerDialog 测试报告

## 设备

| 设备 | 识别名称 |
|---|---|
| rk3568 | `rk3568` |
| 大屏 | `TV` |

## 功能清单

| 设备 | 功能 |
|---|---|
| rk3568 | 电源对话框弹出、熄屏、关机、重启、遥控器焦点导航、鼠标悬停交互、返回键退出、熄屏公共事件 |
| 大屏 | 电源对话框弹出、熄屏、关机、重启、遥控器焦点导航、鼠标悬停交互、返回键退出、熄屏公共事件 |

## 验证点

| 项目 | rk3568 | 大屏 |
|---|---|---|
| 电源对话框弹出 | 长按电源键或系统触发方式正常弹出 | 长按电源键或系统触发方式正常弹出 |
| 三项电源操作渲染 | 熄屏/关机/重启图标+文案完整展示，无第四项 | 熄屏/关机/重启图标+文案完整展示，无第四项 |
| 默认焦点锚点 | 关机项（index=1）默认聚焦高亮 | 关机项（index=1）默认聚焦高亮 |
| 焦点导航 | 方向键切换焦点、高亮边框 | 方向键切换焦点、高亮边框 |
| 确认键操作 | ENTER 触发熄屏/关机/重启 | ENTER 触发熄屏/关机/重启 |
| 鼠标悬停 | 悬停按钮高亮且鼠标样式切换为点击样式 | 悬停按钮高亮且鼠标样式切换为点击样式 |
| 鼠标点击 | 点击按钮触发对应电源操作 | 点击按钮触发对应电源操作 |
| 返回退出 | 返回键/返回手势正常关闭对话框 | 返回键/返回手势正常关闭对话框 |
| 熄屏公共事件 | 熄屏操作发布 powerBoolean 公共事件 | 熄屏操作发布 powerBoolean 公共事件 |
| 窗口透明 | 对话框窗口背景透明，不影响底层显示 | 对话框窗口背景透明，不影响底层显示 |
| 生命周期 | 前后台切换/会话销毁正常回收 | 前后台切换/会话销毁正常回收 |
